# Mod Translation Toolkit v0.5.7

## API change
Automatic translation now requires your own Google Cloud Translation API key.

### Added
- API Settings window
- encrypted local key storage via Windows DPAPI
- built-in Polish/English setup instructions
- billing/quota warning
- official Google Cloud Translation API v2 integration

### Removed
- unofficial shared/public Google Translate endpoint

### Important
Google Cloud charges and quotas apply to the owner of the configured API key.
