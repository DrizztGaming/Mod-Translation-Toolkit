# Mod Translation Toolkit v0.10.11 Experimental

## Learning glossary

The RimWorld contextual glossary can now learn from manual corrections.

Workflow:
1. Automatically translate an entry.
2. Manually correct the result.
3. Toolkit offers to remember the correction.
4. Repeated identical corrections raise confidence.
5. At confidence 3 the learned contextual rule becomes active automatically.

Learning is available for both RimWorld Game Core/DLC and RimWorld Mods.
