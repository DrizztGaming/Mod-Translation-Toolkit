# Mod Translation Toolkit v0.4.0

RimWorld keybind/UI diagnostics.

- explicitly scans `KeyBindingDef`
- uses normal DefInjected translation for exposed label/description fields
- flags keybinds with no localizable label/description
- identifies likely RimWorld UI/code-generated text
- adds a Keybind diagnostics dialog

Smart Speed is the first target case for this diagnostic path.
