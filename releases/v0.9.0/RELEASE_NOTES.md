# Mod Translation Toolkit v0.9.0 Experimental

## Project Zomboid Game scan progress

The Project Zomboid Game profile now shows a real 0-100% scan progress bar.

Progress is split into stages:
- source localization scan
- target localization scan
- index building
- translation matching
- coverage calculation

The UI is refreshed during long scans and the Scan button is temporarily disabled to prevent duplicate work.
