# Mod Translation Toolkit v0.9.7 Experimental

## Workshop upload package

Project Zomboid's in-game uploader expects a staging item that contains:

```
Contents/
  mods/
    <mod>/
preview.png
workshop.txt
```

v0.9.7 generates this package automatically under `%USERPROFILE%\Zomboid\Workshop`.

The existing local translation mod under `%USERPROFILE%\Zomboid\mods` remains separate and playable.
