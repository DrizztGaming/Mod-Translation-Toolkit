# Mod Translation Toolkit v0.8.0

## Project Zomboid experimental foundation

This release adds the first Project Zomboid mod-translation profile.

Current scope:
- B41/B42 translation-folder discovery
- versioned B42 mod folders
- source/target language selection
- standard `key = "value"` table parsing
- existing target translation matching
- manual editing
- automatic translation
- CSV export/import

Not yet included:
- Project Zomboid base-game profile
- `Recorded_Media_*` and other structured translation formats
- building/publishing a separate Project Zomboid translation mod
- automatic Workshop mod discovery
