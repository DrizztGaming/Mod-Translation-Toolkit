# Mod Translation Toolkit v0.10.15 Experimental

## Quiet learning

RimWorld glossary learning no longer needs to interrupt every manual correction.

Default mode: **Silent**
- corrections are queued in the background,
- repeated corrections are merged,
- review them later in **Suggestions / Propozycje**,
- accepted occurrences increase confidence,
- confidence 3+ activates the learned rule.

Available modes: Silent, Ask, Off.
