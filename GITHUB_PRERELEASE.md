# GitHub Prerelease v0.8.0 Experimental

## Tag
`v0.8.0`

## Release title
`Mod Translation Toolkit v0.8.0 Experimental`

## Release type
Mark this release as **Pre-release** on GitHub.

## Recommended asset
`ModTranslationToolkit-v0.8.0.zip`

## Short description
Experimental release introducing the first Project Zomboid Mod profile.

### New
- Project Zomboid Mod tab
- B41/B42 translation-folder discovery
- versioned B42 mod folder support
- source/target language selection
- standard `key = "value"` translation parsing
- existing target matching
- manual editing
- automatic translation
- CSV export/import

### Not yet included
- Project Zomboid base-game profile
- `Recorded_Media_*` parser
- Project Zomboid translation-mod packaging
- automatic Workshop discovery

Stable users should remain on v0.7.8 unless they want to test the Project Zomboid profile.

Use `releases/v0.8.0/RELEASE_NOTES.md` as the full prerelease description.
