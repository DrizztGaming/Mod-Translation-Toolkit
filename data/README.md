# Local EN-PL dictionary

`en-pl-dictionary.csv` is a small, offline starter lexicon maintained with Mod Translation Toolkit and distributed under the repository license. It is intentionally conservative: ambiguous entries include alternatives or context notes. Runtime lookup never calls an external API.

User terminology remains separate in the existing `%APPDATA%\ModTranslationToolkit` glossary files. Glossary rules always take precedence over this bundled lexicon.
